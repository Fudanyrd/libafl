# LibAFL Runtime Library

An attempt of [fuzzbench](https://github.com/google/fuzzbech)
integration. To use it, copy the [env](./env) directory to
`$PATH_TO_FUZZBENCH/fuzzers/libafl_randset`, and
follow the 
[guide to adding a new fuzzer](https://google.github.io/fuzzbench/getting-started/adding-a-new-fuzzer/).

We name our fuzzer `libafl_randset`.
